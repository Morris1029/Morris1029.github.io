# Morris1029.github.io

莫东亮的个人主页，展示教育经历、研究方向、行业实践、代表项目与荣誉认证。

## 技术说明

- 原生 HTML、CSS 与 JavaScript，无运行时依赖
- 响应式单页设计，支持桌面端与移动端
- 直接通过 GitHub Pages 发布
- 首页图片使用响应式 WebP 资源

## 本地预览

在项目目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 4173
```

打开 `http://localhost:4173/`。

## 发布

仓库名为 `Morris1029.github.io`。在 GitHub 仓库的 `Settings → Pages` 中选择：

- Source：`Deploy from a branch`
- Branch：`main`
- Folder：`/(root)`

推送到 `main` 后，网站将发布到 <https://morris1029.github.io/>。
